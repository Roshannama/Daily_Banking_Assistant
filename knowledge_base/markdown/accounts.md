# Fictional SecureBank demo policy: Account access and balances

Not official bank policy or regulatory guidance. Version 1.0.

## access | Account access and balances
Account balance and account access require a trusted customer session and PIN verification for each protected request. The chatbot never treats a customer ID typed in chat as authentication.

## availability | Account access and balances
Available account balance comes only from authorized banking tools. If the bank system is unavailable, the assistant reports data unavailable; it does not guess a balance.
